# Fretwise

Тренажёр нот на гитарном грифе на Flutter. Fretwise помогает связать ноту на нотном стане с её положением на грифе: выбрать один лад, найти все варианты или отметить последовательность нот.

Сейчас основная платформа разработки и проверки — **Linux desktop**.

## Возможности

- Нотный стан со скрипичным ключом, добавочными линиями, диезами и бемолями.
- Интерактивный гриф в стандартном строе **EADGBE**, открытые струны и лады 0–12.
- Русские и международные названия нот: `До-диез (C♯)`, `Ре-бемоль (D♭)`.
- Звук открытых струн и выбранных позиций без подключения к сети.
- Три уровня подсказок и объяснение ошибок.
- Статистика сессии и повтор заданий, в которых были ошибки.
- Горячие клавиши и масштабируемый интерфейс.

## Режимы тренировки

| Режим | Задание |
| --- | --- |
| **Первая позиция** | Найти ноту с минимальным ладом в диапазоне 0–4 |
| **По струне** | Найти ноту на указанной струне в диапазоне 0–12 |
| **Все позиции** | Отметить все положения ноты в диапазоне 0–12 |
| **Серии нот** | Отметить последовательность нот в показанном порядке |

Для серий доступны три этапа:

1. **Этап 1:** 3 натуральные ноты, лады 0–4.
2. **Этап 2:** 5 натуральных нот, лады 0–7.
3. **Этап 3:** 7 нот с диезами и бемолями, лады 0–12.

Обычная сессия состоит из 20 заданий, сессия с сериями — из 5 последовательностей.

## Управление

- **Мышь:** выбор позиции на грифе и кнопок интерфейса.
- **Динамик слева от струны:** прослушать открытую струну.
- **H:** показать следующий уровень подсказки.
- **Enter:** перейти к следующему заданию после правильного ответа.

## Запуск на Linux

Требуются Flutter с поддержкой Linux desktop и системные инструменты сборки. Проект проверен на Flutter **3.44.6**.

```bash
git clone git@github.com:aisho-alex/fretwise.git
cd fretwise
flutter pub get
flutter doctor -v
flutter run -d linux
```

В выводе `flutter doctor -v` раздел `Linux toolchain` должен быть отмечен как готовый.

## Проверка и сборка

```bash
flutter analyze
flutter test
flutter build linux --release
```

Release-приложение появится здесь:

```text
build/linux/x64/release/bundle/guitar_trainer
```

Тесты покрывают музыкальную модель, генерацию заданий, прохождение серий, подсказки, статистику, обработку кликов по грифу и вызовы аудиоплеера.

## Технические особенности

- Позиции вычисляются через MIDI-высоты открытых струн, без ручной таблицы ответов.
- Учитывается гитарная нотация: записанная нота звучит на октаву ниже.
- Энгармонические ноты имеют одинаковые позиции на грифе, но разное отображение на стане.
- Геометрия рисования грифа и определения нажатий общая, поэтому кликабельные области совпадают с изображением.
- В приложении используются синтезированные сэмплы щипка, а не записи настоящей гитары.

## Текущие ограничения

- Linux — единственная платформа, на которой проект сейчас проверяется.
- Статистика и прогресс не сохраняются между запусками.
- Распознавания нот через микрофон пока нет.
